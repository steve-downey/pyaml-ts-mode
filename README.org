* ~pyaml-ts-mode~
Prog-mode YAML treesitter mode

* Installation
#+begin_src elisp
(use-package pyaml-ts-mode
  :commands (pyaml-ts-mode pyaml-ts-mode-install-grammars pyaml-ts-mode-version)
  :vc (:url "https://github.com/steve-downey/pyaml-ts-mode.git"
            :lisp-dir "lisp"
            :rev :newest)
  :mode ("\\.ya?ml\\'" . pyaml-ts-mode)
  :init
  (add-to-list 'major-mode-remap-alist '(yaml-mode . pyaml-ts-mode))
  (add-to-list 'major-mode-remap-alist '(yaml-ts-mode . pyaml-ts-mode))
  )
#+end_src

* Development
The tests are ERT, and need the tree-sitter grammar installed:

#+begin_src bash
make grammar   # install the tree-sitter grammar the tests need
make compile   # byte-compile the mode
make test      # run the ERT suite
#+end_src

Tests that need the grammar skip themselves when it is missing, and the
Flymake tests skip themselves without =yamllint= on =PATH=.  Emacs 31 or
later is required: the mode calls =treesit-ensure-installed=.  Override
the binary with =make EMACS=/path/to/emacs test=.
